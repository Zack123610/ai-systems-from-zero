# Project 03 — LLM Serving Benchmark

Benchmark real inference backends such as Hugging Face Transformers, llama.cpp, vLLM, and optionally SGLang.

Focus: TTFT, TPOT, throughput, p50/p95/p99 latency, concurrency, batching, and context-length scaling.

Paper preparation: vLLM and LLM serving literature.
